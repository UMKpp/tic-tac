# XOX (Tic Tac Toe) Game

A fully featured Tic Tac Toe web application with multiple game modes and level progression!

## Features
- **Play with Friend:** Classic 2-player local mode.
- **Play with Computer:** Challenge an AI opponent.
- **Score Tracking:** Keeps track of wins for Player X, Player O, and draws.
- **Level System:** Advance through levels as you play.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
Simply open `index.html` in any modern web browser to start playing.
